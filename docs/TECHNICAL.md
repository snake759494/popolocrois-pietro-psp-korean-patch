# 기술 문서

## 메시지 블록 (이벤트 `.p01`, 맵 `.p00`)
- 파일은 단순 오프셋 목록 컨테이너(`u32 개수, u32 오프셋…`, 16바이트 정렬)이고, 그 안 메시지 블록 헤더는 다음과 같습니다.
  - `+0x00` 종류(0/1 = 구형식, 종료 코드 `0x13` / 2/3 = 신형식, 종료 코드 `0x1A`), `+0x36` ID, `+0x38` 개수, `+0x3C` 테이블 오프셋
  - 테이블: `u16 번호, u16 길이(종료 코드 포함), u32 블록 기준 오프셋`
- 문자열은 SJIS. 제어 코드: `0x17 화자 0x18`, `0x14 xx`(멈춤), `0x16 xx`(표정), `0x19 01…19 02`(느린 출력), `0x15 03…15 02`(큰 글씨), `0x12`(페이지), `0x0A`(줄바꿈), 선택지 표시 ASCII `&`.
- 한글 문자열은 블록 안 문자열 영역(가장 낮은 문자열 오프셋 ~ 테이블)에 다시 채우고 테이블만 고칩니다. 파일 크기와 다른 데이터는 그대로입니다.
- 주의: 헤더 모양만으로 찾으면 맵 데이터 속 오탐 블록이 생깁니다. 그 "문자열 영역"은 맵 타일 데이터라서 다시 쓰면 필드 배경이 깨집니다. `regioncheck.py` 가 영역 안에 문자열·`$` 이외의 바이트가 있는 블록을 빌드에서 제외하고, 빌드는 변경이 문자열 영역 밖으로 나가지 않았는지 파일마다 검사합니다.

### 탐지 시 주의
- 블록 헤더는 4바이트 정렬이며, 메시지 번호는 연속·정렬이 보장되지 않고 0xFFFF 항목도 있습니다. 번호는 다시 쓰지 않고 그대로 둡니다.
- 문장에 반각 가타카나(`0xA1~0xDF`, 예: `･`)가 들어갈 수 있고, 일부 표는 길이에 종료 코드를 포함하지 않습니다.
- 이벤트·맵 스크립트 안에는 메시지 블록 밖에 직접 들어 있는 문장(줄바꿈 `\n\x0b`, 대기 `$w`, 끝 `@`, NUL 종료)이 있습니다. 같은 길이로 덮어쓰고 남는 바이트는 공백으로 채웁니다(`inline_scan.py`).
- 검증: `audit_kana.py` 가 결과 ISO 전체에서 가나 연속 구간을 찾아 남은 일본어를 보고합니다.

## 폰트 (`data/fonts/*.fnt`, rxFont)
- 헤더(8 / 0x28 / 0x2A바이트, 개수는 빅엔디언 u16), 글리프 레코드 20바이트(폭·전진폭·위아래 여백·x 보정·코드·텍스처 좌표), 정렬된 SJIS 코드 표, `u16 h, u16 w` 와 4bpp 텍스처(0 = 투명, 1 = 가장 진함).
- 한글 음절은 SJIS 한자 코드 `0x889F~` 에 배정하고 한자 글리프를 지운 뒤 아틀라스를 다시 채웁니다. 반각 공백과 문장부호는 전진폭을 줄였습니다.
- 대사 폰트(jk18)는 파일 전체가 메모리에 상주하므로, 크기를 원본과 같게 맞춰(뒤를 0으로 채움) 힙 배치를 원본과 같게 유지합니다.

## 실행 파일 (BOOT.BIN)
- 디스크에 평문 ELF가 있으며 EBOOT.BIN 자리에도 같은 파일을 넣습니다.
- SJIS 문자열은 제자리 덮어쓰기(뒤따르는 0 패딩까지가 예산). 여러 줄 설명은 고정 폭 칸에 그려지므로 원본 줄 길이에 맞춰 다시 줄바꿈합니다.
- 세이브 데이터용 문자열은 UTF-8이라 따로 처리합니다.

## 영상 자막 (`data/telop/*.txt`)
- `시작<TAB>끝<TAB>자막` 형식(CRLF). 시각·명령·끝 표시 줄(`00:00<TAB>00:00`)은 반드시 ASCII여야 하며, 전각으로 바뀌면 끝을 찾지 못해 게임이 멈춥니다. 자막 속 공백은 전각 공백으로 넣습니다.

## 그림 글자
- `gui/*.tm2`(TIM2, 4/8bpp, CSM1 팔레트). 장 제목 카드는 이벤트 파일 `0x370`(팔레트)·`0x770`(헤더)·`0x780`(512×272 8bpp)에 들어 있습니다. 원본 팔레트를 유지하고 가장 가까운 색으로 다시 색인합니다.

## 동영상 (`data/mov/*.pmf`)
- 프레임을 디코딩해 일본어 글자를 인페인팅으로 지우고 한글을 같은 위치·투명도로 그린 뒤 x264로 재인코딩하고, 원래 PES 슬롯에 넣어 파일 크기와 컨테이너를 유지합니다(`op_mux.py`).
